## 11 · Agents, tools, and the Model Context Protocol · [evidence](../slides/11-plain-language-definitions/)

```text
Plain-language definitions
Agents, tools, and the Model Context Protocol
The model
A language model answers from what it read in training. It cannot see your files or run your code.
The agent
A loop around the model: read the goal, call a tool, read the result, decide the next call.
The harness
The program you actually run. It owns the loop, the files it may touch and the permissions.
The protocol
MCP is the USB-C port for agents: describe a server once, and any agent that speaks MCP can use it.
CARC · UNM · CS Colloquium · Nov. 4, 2026
```

> **Notes:** [~2 min · by 18:00] The important card is the fourth: MCP means the server you stand up once is usable from every agent your group already uses (Claude Code, Codex, Antigravity, OpenCode, Goose). MESA’s MCP servers are public today.
